# サプリメント記録の編集

- 日付: 2026-07-25
- ステータス: 採用
- 関連: [[decision-20260724-supplement-intake]] / UI 設計 v0.7（食事記録のインライン編集）
- 対応 issue: #31（登録したサプリメント記録を編集できるようにしたい）

## 背景

サプリメント記録は追加・削除はできたが編集ができず、量や製品名を直したいときは
一度削除して入力し直す必要があった。食事記録は既に `PUT /api/meals/{meal_id}` で
インライン編集できる（UI 設計 v0.7）。同じ体験をサプリにも揃える。

## 決定

食事記録の編集と同型で実装する。

### API
- `PUT /api/supplements/{supplement_id}`（新設・全 23 オペレーション）。
- 差し替えるのは **製品名と栄養素の量のみ**。`supplement_id` / `date` / `recorded_at` は不変
  （記録した日と同一性を保つ。食事編集で `date`・`meal_type` を触らないのと同じ方針）。
- バリデーションは保存時と共通化（`validateSupplementBody` を `saveSupplement` から抽出）。
  不正時はフィールドコードのみ返し、**製品名を error/log に載せない**（logging allowlist 順守）。
- 未知 id は 404、不正入力は 422。

### UI（`SupplementPanel`）
- 保存済みカードに「編集」ボタンを追加（既存の「削除」の左）。
- モーダルなしのインライン編集（`EditMode`）。製品名・栄養素行を保存時と同じ入力で表示し、
  **やめる / 保存** の2アクション。0件の量にする編集は保存不可（削除へ誘導）。
- 日付・区分の変更、記録の複製は対象外（意図的に最小スコープ）。

## 影響

- テスト 198 → 201（`updateSupplement` のユニット3件：置換・404・製品名を漏らさない422）。
- 契約 22 → 23 オペレーション（`check:api-contract` pass）。
- 既存データ・凍結 seed は不変。判定ロジック（食品＋サプリ合計）にも変更なし。
