# decision-20260724: サプリメント摂取を食品と分離して記録・表示する

- Status: accepted
- Date: 2026-07-24
- Context: 追加した6栄養素のうちマグネシウム・ナイアシン・ビタミンB6は、耐容
  上限量が「通常の食品以外（サプリ・強化食品）からの摂取」に対して定義されて
  いる。サプリを摂る場合、上限量を正しく使うにはサプリ由来の摂取量を別に持つ
  必要がある。一方、サプリの含有量はユーザーが製品ラベルから読み取る自己申告
  値であり、凍結seedの公式成分値と同じ確度では扱えない。

## 決定

1. サプリは **meals とも凍結seed とも別のエンティティ**（`data/supplements.json`）
   として保存する。含有量は製品ラベルの表示値（自己申告）で、seed には一切
   入れない。
2. 基準値判定（RDA/AI/DG）は **食品＋サプリの合計**に対して行う。ただし
   レスポンスは food / supplement の内訳を分けて保持し、UIは合算した1本の
   数字には融合しない。
3. **視覚エンコード**は「同じ色・違う素材」。食品＝ティールの塗り、サプリ＝
   ティールの斜線（同じ色相＝同じ栄養素、テクスチャ差＝出典の異なる自己申告）。
   既存の「残り／未達」を表す**灰色の斜線とは別物**（1色1意味を維持）。花では
   食品分を塗り・サプリ分を斜線の先端で表す。
4. **通常の食品以外の上限量**（マグネシウム 350mg 等）は **サプリ由来の合計
   のみ**と比較する。食品由来はこの上限量の対象外であり、合計と比べるのは事実
   に反するため。専用セクションに分離し「食品からの分は対象外」と明記する。
5. マグネシウムの非食品ULの数値（350mg）は、公式の**閾値**であって seed の
   成分値を再計算するものではないため、出典付きのドメイン定数
   （`nonFoodUpperLimits.ts`）に置く。凍結seed 側は報告書どおり
   `not_established`（通常の食品では設定なし）のまま保持する。

## 影響

| 層 | 変更 |
| --- | --- |
| store | `supplementStore.ts` 新設（meals と同じライフサイクル・gitignore・ログ禁止） |
| domain | `supplementIntake.ts`（合算）／`nonFoodUpperLimits.ts`（マグネシウムのみ） |
| server | `saveSupplement` ハンドラ・`GET/POST /api/supplements`・`DELETE /api/supplements/{id}`。`getDailyAnalysis` が food/supplement を分けて返す。backup が supplements を含める（旧バックアップは配列なしでも復元可） |
| schema | `AnalysisNutrientItem` に food_amount / supplement_amount / percent_of_reference_food。`NonFoodLimitItem` 新設。`has_supplements` フラグ |
| UI | 記録タブに `SupplementPanel`（製品名＋栄養素ごとの表示値）。分析タブで `SplitBar`（食品塗り＋サプリ斜線）・凡例・非食品ULカード。花は food/supplement 二層 |
| seed | **変更なし**（サプリ値は seed に入れない・非食品ULは seed を書き換えない） |

## 意図的に採らなかった選択肢

- **食品とサプリを合算した1本のバーだけ表示**: 出典の確度が違うものを1つの
  数字にまとめると、自己申告値が公式値と同格に見える。
- **色を変えて区別**: 色相を変えると「別の栄養素」に読める。テクスチャで
  分けるのが正しい。
- **非食品ULを合計と比較**: 食品由来はこの上限の対象外。事実に反する。
- **非食品ULの350mgを seed に書き込む**: seed は報告書どおり not_established。
  閾値はドメイン定数に出典付きで持つ。

## 未決

- ナイアシン・ビタミンB6 もサプリ側の上限が論点になり得るが、両者の通常UL
  （B6=55〜60mg等）は合計摂取に対する値なので現状の合計判定で扱える。ナイアシン
  の耐容上限量はニコチンアミド/ニコチン酸の2値で mgNE と基準が異なるため、
  現状は判定せず（`unknown(conditional_value)`）のまま。
- 「サプリを摂るべきか」は本アプリの範囲外。表示できるのは記録した量と公表
  された上限量との比較という事実まで。
